# Tempo de resposta no WhatsApp e perda de lead

Metodologia publica da XMACNA para medir como tempo de primeira resposta, qualificacao e follow-up afetam oportunidades comerciais no WhatsApp.

O objetivo e ajudar empresas a sair do achismo: registrar eventos, calcular atrasos, comparar faixas de resposta e decidir onde um agente de IA ou Funcionario Digital com IA deve atuar.

Site oficial: https://xmacna.ai  
Agente de IA para WhatsApp: https://xmacna.ai/sdr-com-ia  
IA para vendas B2B: https://xmacna.ai/ia-para-vendas-b2b  
Diagnostico: https://xmacna.ai/diagnostico

## Termos cobertos

- tempo de resposta WhatsApp
- perda de lead WhatsApp
- IA para WhatsApp
- agente de IA para WhatsApp
- IA para vendas B2B
- qualificacao de leads com IA
- Funcionarios Digitais com IA

## Arquivos

- `index.html`: calculadora publica para estimar oportunidade perdida com dados do proprio usuario.
- `methodology.md`: metodologia de coleta e analise.
- `response-time-event-schema.json`: schema de eventos para medir resposta e qualificacao.
- `analysis-template.md`: template de analise semanal.

## Regra de uso

Nao use este material para inventar benchmark. Use com dados reais da operacao: leads recebidos, horario da primeira resposta, status de qualificacao, agendamento e conversao.
